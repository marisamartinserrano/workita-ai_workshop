## MODIFIED Requirements

### Requirement: Job Preferences nav item renders the profile form
The Job Preferences sidebar nav item SHALL render the Job Preferences form section instead of a chat flow.

#### Scenario: User clicks Job Preferences
- **WHEN** an authenticated user clicks Job Preferences in the sidebar
- **THEN** the Job Preferences form is shown with any previously saved values pre-filled

### Requirement: CV Analysis nav item renders the CV section
The CV Analysis sidebar nav item SHALL render the CV & Analysis section instead of a chat flow.

#### Scenario: User clicks CV Analysis
- **WHEN** an authenticated user clicks CV Analysis in the sidebar
- **THEN** the CV textarea and Analyse CV button are shown

### Requirement: LinkedIn Analysis nav item renders the LinkedIn section
The LinkedIn Analysis sidebar nav item SHALL render the LinkedIn section instead of a chat flow.

#### Scenario: User clicks LinkedIn Analysis
- **WHEN** an authenticated user clicks LinkedIn Analysis in the sidebar
- **THEN** the LinkedIn URL field and Get Recommendations button are shown
