# workita-ai_workshop

AI workshop project — full-stack web application.

## Structure

```
workita-ai_workshop/
├── backend/    # Node.js + Express + TypeScript + Prisma
├── frontend/   # React
├── docs/       # API specs and standards
└── docker-compose.yml
```

## Getting started

### Prerequisites
- Node.js >= 18
- Docker & Docker Compose

### Run the database

```bash
docker-compose up -d
```

### Backend

```bash
cd backend
npm install
npm run dev
```

### Frontend

```bash
cd frontend
npm install
npm start
```
